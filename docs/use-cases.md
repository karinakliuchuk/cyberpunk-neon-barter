# Специфікації Use Case

## UC-01 «Створення оголошення обміну»

| Поле | Опис |
|---|---|
| ID і назва | UC-01 «Створення оголошення обміну» |
| Мета | Додати до системи коректне оголошення обміну («віддаю» або «потребую»), яке стане доступним для пошуку 3-стороннього циклу. |
| Основний актор | Учасник ринку |
| Тригер | Учасник має ресурс, який готовий віддати, або потребує ресурсу, і розпочинає створення оголошення. |
| Передумови | Учасник має зареєстровану картку (позивний і контакт). Список категорій (вода, їжа, ліки, зв'язок, енергія) доступний. |
| Основний сценарій | 1. Учасник обирає тип оголошення: «віддаю» або «потребую».<br>2. Обирає категорію зі списку.<br>3. Вводить кількість у стандартних цілих одиницях.<br>4. Передає дані системі.<br>5. Система перевіряє, що всі обов'язкові поля заповнені.<br>6. Система перевіряє, що учасник зареєстрований.<br>7. Система перевіряє, що категорія входить до фіксованого списку.<br>8. Система перевіряє, що кількість є цілим числом більшим за нуль.<br>9. Система зберігає оголошення зі статусом «Активне».<br>10. Система повідомляє про успішне створення і показує підтвердження. |
| Альтернативний / помилковий сценарій | **A1.** На кроці 5 не заповнено обов'язкові поля — система не зберігає оголошення і вказує, яких полів бракує.<br>**A2.** На кроці 6 учасника не знайдено серед зареєстрованих — система не зберігає оголошення і повідомляє, що потрібна реєстрація картки.<br>**A3.** На кроці 7 категорія не входить до списку — система не зберігає оголошення і повідомляє про недопустиму категорію.<br>**A4.** На кроці 8 кількість дорівнює нулю, від'ємна або дробова — система не зберігає оголошення і повідомляє причину. |
| Постумови | **Успіх:** нове оголошення зі статусом «Активне» збережене і доступне для пошуку циклу обміну. **Помилка:** набір оголошень у системі не змінено. |
| Пов'язані вимоги | FR-02, FR-03, FR-04, FR-05, NFR-01, NFR-04, NFR-05 (передумова: FR-01) |
| Критерії приймання | AC-02, AC-03, AC-04, AC-05, AC-09, AC-12, AC-13 |

Правила FR-03 і FR-04 впливають на кроки 7 і 8, а FR-05 — на кроки 5 і 6. Ці розгалуження відображено на Activity Diagram ([model/activity-uc-01.md](../model/activity-uc-01.md)).
