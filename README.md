# Cyberpunk Neon Barter

> REST API сервіс для організації багатостороннього бартерного обміну в неоновому світі майбутнього.

---

## Опис проєкту

Основна системна логіка реалізує алгоритм циклічного бартерного обміну послугами та ресурсами за схемою **A → B → C → A**, що дозволяє користувачам знаходити оптимальні ланцюжки обміну без безпосереднього використання грошового еквівалента.

## Інструкція з локального запуску

Для запуску проєкту вам знадобиться **Docker Desktop** та **.NET 9 SDK**.

### 1. Клонувати репозиторій

```bash
git clone https://github.com/karinakliuchuk/cyberpunk-neon-barter.git
cd cyberpunk-neon-barter
```

### 2. Запустити базу даних PostgreSQL

У корені проєкту є налаштований `docker-compose.yaml`. Запустіть базу даних однією командою:

```bash
docker compose up -d
```

*Це підніме контейнер `cyberpunk-db` на порту 5432 та створить volume для збереження даних.*

### 3. Застосувати міграції (створити таблиці)

Щоб створити необхідну структуру таблиць у базі даних, виконайте:

```bash
dotnet ef database update --project src/CyberpunkNeonBarter.Infrastructure --startup-project src/CyberpunkNeonBarter.Api
```

### 4. Запустити Web API

```bash
dotnet run --project src/CyberpunkNeonBarter.Api
```

Після успішного запуску сервер буде доступний за адресою `http://localhost:5254`.

## Робота з системою

### Вебінтерфейс (Рекомендовано)

Для зручної роботи з системою без використання сторонніх інструментів перейдіть у браузері за посиланням:

👉 [**http://localhost:5254/**](http://localhost:5254/)

На сторінці доступний зручний інтерфейс користувача:
1. Натисніть **«Увійти в систему»**, а потім **«Увійти як тестовий користувач»** (це автоматично згенерує JWT-токен).
2. У головному меню оберіть **«Створити оголошення»**, щоб додати новий ресурс.
3. Оберіть **«Переглянути всі оголошення»**, щоб побачити список усіх збережених у базі даних записів (найновіші відображаються зверху).

### Swagger UI (Для розробників)

Для тестування API на рівні HTTP-запитів доступний стандартний Swagger UI:

👉 [**http://localhost:5254/swagger**](http://localhost:5254/swagger)

*Для тестування захищених ендпоінтів викличте `POST /api/auth/login`, отримайте JWT-токен та натисніть кнопку `Authorize`.*

### Модульні тести

```bash
dotnet test tests/CyberpunkNeonBarter.Tests/CyberpunkNeonBarter.Tests.csproj
```

## Неперервна інтеграція (CI)

У репозиторії налаштовано автоматичний CI-пайплайн за допомогою **GitHub Actions** (`.github/workflows/build-and-test.yml`).

Пайплайн запускається при кожному `push` або `pull_request` у гілку `main` та виконує такі кроки:

1. Перевіряє та відновлює залежності .NET 9.
2. Виконує автоматичне збирання проєкту (`dotnet build`).
3. Запускає повний набір модульних тестів (`dotnet test`).
