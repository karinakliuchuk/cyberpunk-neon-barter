# Cyberpunk Neon Barter`n`nREST API сервіс для організації багатостороннього бартерного обміну.`n`n## Опис проєкту`nПроєкт розроблено в межах лабораторної роботи №2 з дисципліни Технології розробки програмного забезпечення (група ТР-41). Системна логіка реалізує механізм циклічного обміну послугами та ресурсами за схемою A -> B -> C -> A.`n`n## Технологічний стек`n- C# / .NET 8 (ASP.NET Core Web API)`n- xUnit (модульне тестування)`n- GitHub Actions (CI пайплайн)`n`n## Інструкція з локального запуску`n1. Відновити залежності:`n   dotnet restore`n`n2. Побудувати проєкт:`n   dotnet build --no-restore`n`n3. Запустити модульні тести:`n   dotnet test tests/CyberpunkNeonBarter.Tests/CyberpunkNeonBarter.Tests.csproj`n`n4. Запустити Web API:`n   dotnet run --project src/CyberpunkNeonBarter.Api
